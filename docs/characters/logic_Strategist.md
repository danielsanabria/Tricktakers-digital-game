# Strategist (1C)

## Overview
*   **Rank:** 1C
*   **Difficulty:** Expert
*   **Key Mechanic:** Traps & Pooled Points

## Abilities

### Trap Placement (Setup)
*   **Trap Deck:** Order your 5 Trap Cards. One is revealed before each trick.
*   **Immunity:** You are immune to your own traps.

### Trap Activation (Each Trick)
1.  **Reveal:** Reveal the trap for this trick.
2.  **Trigger:** If an opponent meets the trap condition (e.g., plays a Black Card):
    *   They lose **-10 pts** immediately.
    *   These points go into a **Central Pool** (the Pot).
    *   *Limit:* Opponents cannot drop below 0 pts. If at 0, no points go to the pool.

### Taking the Pot
*   **Winning the Trick:** If you (Strategist) win the trick, you collect all points currently in the Central Pool.
*   **Not Winning:** The points stay in the pool for the next trick.
*   **End of Round:** Points remaining in the pool are lost (returned to supply).

### Tactical Maneuver
Once per round, you may ignore the **Must Follow** rule when playing a card.

## Win Conditions
1.  **5 Tricks:** If you win all 5 tricks, you instantly win the game.

## Scoring
At the end of the round, you have **choices** based on wins:

| Tricks Won | Reward |
| :--- | :--- |
| **0** | Choose: **+50 pts** OR **Take Rare Card** (for next round) |
| **1** | Choose: **+30 pts** OR **Take Black 7** (for next round) |
| **2** | -50 pts |
| **3** | +50 pts |
| **4** | +80 pts |
| **5** | Win Game |
